# 需求文档（v1.0，阶段 0 已确认）

状态：阶段 0 已对齐确认（2026-11-18），详见 [decisions/](./decisions/) 下各 ADR。

## 1. 概述
陪玩售后助手。陪玩电脑上的轻量客户端在《三角洲行动》启动后自动在本地录制双音轨语音和画面。陪玩师通过一键开关标记接单时段；仅接单时段的录像在退出游戏或电脑空闲时自动断点续传至云端，私人对局仅本地保留 3 天后自动清理，绝不自动上云。发生售后纠纷时，售后人员在网页端选中接单记录并输入自然语言投诉，系统结合双音轨语音转写与语义检索给出 3～5 个候选时间点及关键帧缩略图，售后人员点击跳转核对并自行判断责任。

## 2. 用户
| 角色 | 做什么 |
|---|---|
| 陪玩师 | 安装小助手、授权录制；正常打游戏（自动兜底录屏），接单时一键切换「开始/结束接单」，必要时对漏点接单的 3 天内本地录像手动授权补传 |
| 售后人员 | 按工作室隔离范围查接单录像、输入自然语言投诉、核对双音轨对话与关键帧时间点、记录处理结果 |
| 工作室管理员 | 管理本工作室陪玩师与售后账号、设置云端录像保留天数 |

## 3. 用户故事
- **U1** 作为陪玩师，我安装并授权后，打开《三角洲行动》时小助手自动在本地开始录制，游戏退出时自动停止，防止忘录。
- **U2** 作为陪玩师，我可以通过托盘或小窗一键切换「开始接单 / 结束接单」（可选填订单号/备注）；未点接单的私人对局绝不会自动上传，本地保留 3 天后自动清理；若偶有漏点接单，3 天内我也能手动授权补传对应片段。
- **U3** 作为陪玩师，录制与上传不影响游戏帧数和网络延迟：仅在退出游戏或电脑空闲时才后台上传，游戏过程中零上行带宽占用。
- **U4** 作为售后人员，我选中一条接单记录并输入客户投诉，系统在几秒内给出 3～5 个候选时间点，每个附带说话人区分（陪玩/老板）的语音文字和关键帧缩略图。
- **U5** 作为售后人员，我点击时间点，播放器直接跳到该位置前后并同步高亮对应对话。
- **U6** 作为售后人员，我能对照订单备注或约定逐条核对证据并记录结果。
- **U7** 作为管理员，我能设置本工作室云端录像保留天数，到期自动删除。

## 4. 功能要求
### 客户端（陪玩电脑 - C# .NET 8）
- **R1 自动检测与启停**：通过进程名列表检测《三角洲行动》启动和退出，自动开始和停止本地录制；托盘图标和状态提示始终可见，可随时暂停。
- **R2 双音轨分离录制**：通过 `WASAPI` 独立录制两路音轨——音轨 1 为陪玩师麦克风，音轨 2 为系统声音（含语音软件中老板语音与游戏声），禁止混成单轨。
- **R3 画面采集与硬件降级**：独立子进程通过 `Windows.Graphics.Capture` + 精简 FFmpeg 硬件编码（NVENC/AMF/QSV）录制 720p 低码率视频；无可用硬编时自动降级为双音轨音频 + 低帧率关键截图序列。
- **R4 接单状态开关与物理隔离**：支持一键切换「开始接单 / 结束接单」（可选填订单号/备注），状态切换即时触发切片分段边界，确保接单切片与私人切片物理文件隔离；仅接单切片自动进入上传队列，本地全量缓存默认保留 3 天后自动清理。
- **R5 闲置断点续传与漏录补传**：仅在游戏退出或系统空闲时启动后台分片断点续传，游戏运行期挂起上传；支持 3 天内经陪玩师本人显式确认后手动补传漏点接单的本地片段。
- **R6 资源目标**：录制时 CPU 平均 ≤3%，内存 ≤200 MB（待真实环境压测验收）。

### 云端（全链路 `studio_id` 隔离）
- **R7 双音轨 ASR 与幻觉过滤**：分别对音轨 1（陪玩）和音轨 2（系统/老板）进行静音检测（VAD）与带时间戳语音转写，过滤无语音时的模型幻觉。
- **R8 行业词表与语义检索（MVP）**：结合《三角洲行动》及陪玩行业词表/拼音模糊匹配降低漏检；以自然语言投诉进行混合检索（向量语义 + 关键词），按每段抽取关键帧缩略图，返回 Top 3～5 候选时间点。
- **R9 会话归档与多租户隔离**：按 `(studio_id, player_id, started_at, ended_at)` 及可选订单号/备注归档接单会话；数据库与对象存储全链路强制 `studio_id` 隔离（试点期先启用默认试点工作室）。
- **R10 二期规划（MVP 不做）**：游戏画面 OCR（结算面板、撤离结果）、多模态挂机事件检测、外部派单系统自动同步。

### 售后网页
- **R11 售后工作台**：租户账号登录、按陪玩师/时间/订单备注筛选接单记录、录像播放器（支持点击时间点精确跳转与缩略图预览）、投诉检索输入框、双角色对话时间轴。
- **R12 状态提示**：加载中、无结果、出错三种状态均有明确提示。

## 5. 不做的事（第一版 MVP）
- 收入展示、休息提醒、快捷点外卖。
- 自动判定责任（系统只提供定位证据，判断由售后人员做）。
- 游戏画面 OCR 与多模态事件识别（留待二期）。
- 对接外部派单系统（留待二期）。
- 其他游戏（仅支持《三角洲行动》）及手机端。

## 6. 安全红线
- **S1 反作弊**：客户端仅通过系统进程列表检测游戏，使用 `Windows.Graphics.Capture` 与 `WASAPI` 系统接口采集（与 OBS 同类合规机制）。严禁任何进程注入、API Hook、读取游戏内存、修改游戏文件或在游戏画面上方渲染 Overlay 叠加层。
- **S2 知情同意**：安装时陪玩师明确授权；录制时托盘图标与「私人本地录制 / 接单录制中」状态提示可见；不做隐藏运行。接单前应告知老板对局会录屏用于售后核验。
- **S3 数据隔离**：所有业务数据表、接口鉴权与对象存储路径强制以 `studio_id` 隔离，售后人员仅可访问所属工作室数据。
- **S4 保留期限**：客户端本地私人及已上传缓存默认保留 3 天自动清理；云端接单录像与转写到期自动删除（默认天数见 Q2）。
- **S5 传输与存储**：上传与接口均走 HTTPS，对象存储启用服务端加密，媒体访问使用短期签名 URL。
- **S6 日志脱敏**：服务端与客户端日志禁止输出语音转写原文、用户密钥与签名 Token。

## 7. 验收指标
- 准备 10～20 段标注好纠纷时间点的双音轨录屏作为标准测试集。
- 自然语言投诉检索结果前 3 个中包含正确时间点的比例 ≥80%。
- 1 小时接单录像从上传完成到可检索 ≤10 分钟。
- 客户端资源占用满足 R6，且游戏运行期间上行上传带宽占用为 0。
