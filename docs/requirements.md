# 需求文档（草稿 v0.1）

状态：起草中，待确认。确认前不写业务代码。

## 1. 概述
陪玩售后助手。陪玩电脑上的小助手在《三角洲行动》启动后自动录制画面和语音，录像上传云端分析。发生售后纠纷时，售后人员输入客户投诉，系统给出录像中可能相关的时间点，售后人员点击跳转核对，自己判断责任。

## 2. 用户
| 角色 | 做什么 |
|---|---|
| 陪玩师 | 安装小助手、授权录制、正常接单打游戏 |
| 售后人员 | 查录像、输入投诉、核对证据、记录处理结果 |
| 工作室管理员 | 管理陪玩师和售后账号、设置录像保留天数 |

## 3. 用户故事
- **U1** 作为陪玩师，我安装并授权后，打开三角洲时小助手自动开始录制，游戏退出时自动停止，我不需要手动操作。
- **U2** 作为陪玩师，录制时我能看到托盘图标和录制提示，可以随时暂停。
- **U3** 作为陪玩师，录制不影响游戏帧数。
- **U4** 作为售后人员，我选中一个订单，输入客户投诉，系统在几秒内给出 3～5 个候选时间点，每个附带当时的语音文字或画面事件说明。
- **U5** 作为售后人员，我点击时间点，播放器跳到该位置前后。
- **U6** 作为售后人员，我能对照订单约定（时长、要求、价格）逐条核对。
- **U7** 作为管理员，我能设置录像保留天数，到期自动删除。

## 4. 功能要求
### 客户端（陪玩电脑）
- R1 检测游戏进程启动和退出，自动开始和停止录制。
- R2 同时录制麦克风和系统声音（包括语音聊天里老板的声音）。
- R3 有独立显卡时用硬件编码录 720p 低码率视频；没有时降级为音频加低帧率截图。
- R4 每局结束后后台上传，断网时本地暂存，恢复后补传。
- R5 资源目标：录制时 CPU 平均 ≤3%，内存 ≤200 MB（待实测）。

### 云端
- R6 语音转写成带时间戳的文字，过滤无语音时模型编造的句子。
- R7 行业词表和拼音模糊匹配，降低错字导致的漏检（如"变声器"被转成"变成气"）。
- R8 画面识别：结算界面、撤离结果、长时间画面不动（疑似挂机）。
- R9 投诉检索：语音类问题用向量检索，画面类问题查事件记录，合并后返回候选时间点。

### 售后网页
- R10 订单列表、录像播放器、投诉输入、候选时间点列表。
- R11 加载中、无结果、出错三种状态都有提示。

## 5. 不做的事（第一版）
- 收入展示、休息提醒、快捷点外卖。
- 自动判定责任。系统只给证据，判断由人做。
- 其他游戏。只支持《三角洲行动》。
- 手机端。

## 6. 安全红线
- **S1 反作弊**：客户端只能通过进程列表检测游戏，用 Windows 系统接口截屏和录音（与 OBS 同类方式）。禁止注入游戏进程、读取游戏内存、修改游戏文件、在游戏画面上叠加内容。
- **S2 知情同意**：安装时陪玩师明确授权；录制时托盘图标和提示可见；不做隐藏运行。接单时应告知老板对局会录屏用于售后。
- **S3 数据隔离**：工作室之间的数据完全隔离，售后人员只能看本工作室的录像。
- **S4 保留期限**：录像和转写到期自动删除，默认天数待定。
- **S5 传输与存储**：上传使用 HTTPS，云端存储加密，访问链接有时效。
- **S6 日志**：日志中不记录语音文字原文和账号密钥。

## 7. 验收指标
- 准备 10～20 段标注好纠纷时间点的录屏作为标准答案集。
- 检索结果前 3 个中包含正确时间点的比例 ≥80%。
- 1 小时录像从上传完成到可检索 ≤10 分钟。
- 客户端资源占用满足 R5。
